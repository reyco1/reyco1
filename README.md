Here's what I'm working on at [Welby Health](https://welbyhealth.com/), plus the open-source tools I maintain.

### What I'm building

- [**Markus**](https://reyco.me/projects/markus) is Welby's clinical AI teammate for nurses. It answers from live patient data and shows its reasoning. Live at [markus.getwelby.com](https://markus.getwelby.com).
- [**Agent Console**](https://reyco.me/projects/agent-console) is a desktop app for running a team of AI agents. Each agent gets its own role, terminal and daily budget. The code is private, so the project page is the best look.
